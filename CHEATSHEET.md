## 2. Скелет программы

```cpp
#include <iostream>       // директива: подключить библиотеку ввода-вывода

int main()                // главная функция, точка входа
{
    // это комментарий, компилятор его игнорирует
    std::cout << "Привет!";  // инструкция, обязана заканчиваться точкой с запятой!
    return 0;             // 0 = "программа завершилась успешно"
}
```

| Термин | Что это |
|---|---|
| **main()** | Функция, с которой начинается выполнение программы |
| **Инструкция** | Одна команда компьютеру, заканчивается `;` |
| **Комментарий** | Заметка для людей: `// одна строка` или `/* много строк */` |
| **return** | Вернуть значение и выйти из функции |

## 5. Операторы и математика

| Термин | Что это | Пример |
|---|---|---|
| **Целочисленное деление** | При делении целых чисел дробная часть отбрасывается | `5 / 2 = 2` |

## 12. Работа с массивами

### Объявление и инициализация
```cpp
int arr[5];                 // массив из 5 целых чисел
int numbers[] = {1, 2, 3, 4};  // инициализация при объявлении
```

### Доступ к элементам
Индексы начинаются с 0:
```cpp
arr[0] = 10;  // присваивание значения
int value = arr[1];  // чтение значения
```

### Важные моменты
- Массивы имеют фиксированный размер, определяемый при объявлении.
- Размер массива можно узнать через `sizeof(arr) / sizeof(arr[0])`.
- Выход за пределы массива приводит к неопределённому поведению.

## 13. Дополнительные операции со строками (std::string)

### Методы строк
- `length()` — возвращает длину строки.
- `substr(start, length)` — возвращает подстроку.
- `find(substring)` — ищет подстроку в строке.
- `append(str)` — добавляет строку в конец.
- `empty()` — проверяет, пуста ли строка.

### Пример использования методов:
```cpp
string s = "Hello, world!";
int len = s.length();         // len = 13
string sub = s.substr(7, 5);  // sub = "world"
int pos = s.find("world");    // pos = 7
s.append(" and goodbye!");    // s = "Hello, world! and goodbye!"
bool isEmpty = s.empty();     // isEmpty = false
```

## 14. Типичные ошибки и предостережения

### При работе с массивами:
- **Выход за пределы массива:**
  ```cpp
  int arr[5];
  arr[5] = 10;  // ошибка! индекс 5 не существует
  ```
- **Неинициализированные элементы:**
  Если массив не инициализирован, его элементы могут содержать мусорные значения.

### При работе со строками:
- **Использование кириллических символов в идентификаторах:**
  ```cpp
  string sЗ;  // неправильно! (кириллическая «З»)
  string s3;  // правильно (цифра «3»)
  ```
- **Забытое подключение `<string>`:**
  Не забудьте добавить `#include <string>` в начало файла.

## 16. Перечисления (enum)

| Термин | Что это | Пример |
|---|---|---|
| **enum** | Свой тип с фиксированным списком значений ("меню") | `enum GameState { MENU, PLAYING, PAUSE };` |
| **Перечислитель** | Имя из списка; внутри — число, по умолчанию с 0 | `MENU=0, PLAYING=1, PAUSE=2` |
| **Своя нумерация** | Можно задать стартовое значение | `enum months { jan = 1, feb };` → jan=1, feb=2 |
| **Защита от int** | Присвоить голое число нельзя — только приведением | `band = spectrum(band + 1);` |

**Когда использовать enum:** когда у переменной небольшой фиксированный список смыслов (состояния игры, дни недели, коды ошибок, сложности).

```cpp
enum GameState { MENU, PLAYING, GAME_OVER };
GameState state = PLAYING;       // читаемо и защищено от мусора вроде 42
if (state == GAME_OVER) { ... }  // читается как английский текст
```

## 17. Указатели (Pointers) — главы 4

### Что такое указатель?
**Указатель** — переменная, в которой хранится **адрес другой переменной**.

| Термин | Что это | Пример |
|---|---|---|
| **`&`** | Оператор взятия адреса | `int a = 10; int* ptr = &a;` |
| **`*`** (деф) | Оператор разыменования (доступ к значению по адресу) | `cout << *ptr;` // 10 |
| **`*ptr`** | Значение по адресу `ptr` | `int value = *ptr;` |
| **`&variable`** | Адрес переменной | `&a` → адрес где лежит `a` |

### Примеры указателей:
```cpp
int a = 42;
int* ptr_to_a = &a;     // ptr хранит адрес a
*ptr_to_a = 100;        // меняем значение a на 100
cout << *ptr_to_a;      // 100

int b = *ptr_to_a;      // копирование значения: b = 100
```

### Типы указателей:
- `int* ptr` — указатель на целое число
- `double* dptr` — указатель на двойное число
- `char* str` — часто используется для строк

### Важные моменты:
- Указатели позволяют **менять значения переменных из функции** (через обратную ссылку).
- **Пустой указатель** (`nullptr` или `NULL`) — не указывает ни на что.
- **Выход за пределы** — доступ к памяти, которая не принадлежит программе = **неопределённое поведение**!

## 18. Динамическая память и указатели (New/Delete)

### Объявление указателя:
```cpp
int* ptr;              // объявление указателя на int
int* ptr2 = new int(); // создание и инициализация с новым целым
```

### Создание памяти с `new`:
| Оператор | Что делает | Пример |
|---|---|---|
| `new int` | Выделить память под одно int | `int* p1 = new int(42);` |
| `new double` | Выделить память под double | `double* p = new double(3.14);` |
| `new T[n]` | Выделить массив из n элементов | `int* arr = new int[10];` |

### Освобождение памяти с `delete`:
```cpp
int* ptr = new int(100);
*ptr = 200;           // используем память
delete ptr;           // освобождаем память
// after delete, ptr is still valid but should not be used!
```

### Динамический массив:
```cpp
int* arr = new int[5];      // массив из 5 целых
arr[0] = 1; arr[1] = 2;
delete[] arr;               // освобождение массива (важно: delete[], а не delete!)
```

### Встроенный конструкторы (smart pointers):
С C++11 появились **умные указатели** — они сами освобождают память:

| Тип | Что делает |
|---|---|
| `unique_ptr<T>` | Владение одним объектом, автоматическое удаление |
| `shared_ptr<T>` | Совместное владение, подсчёт ссылок |

Пример:
```cpp
#include <memory>

unique_ptr<int> p1 = make_unique<int>(42); // автоматически удалится при выходе из области видимости
```

### Типичные ошибки:
- **Double delete**: `delete ptr; delete ptr;` → **сегфолт!**
- **Use after free**: использование указателя после `delete` → **неопределённое поведение!**
- **Забытое освобождение**: утечка памяти (memory leak)
- **delete массива как обычного**: `delete arr[5]` вместо `delete[] arr`

## 19. Структуры (struct) и объединение с указателями

### Определение структуры:
```cpp
struct Point {
    double x, y;      // поля (members)
};
Point p(3.0, 4.0);   // создание объекта
cout << p.x;         // доступ к полю
```

### Стрелочная операция (`->`):
```cpp
Point* ptr = &p;     // указатель на структуру
cout << ptr->x;      // эквивалентно (*ptr).x
```

### Пример структуры с указателем:
```cpp
struct Student {
    string name;
    int age;
};

Student s = {"Alice", 20};
Student* p = &s;

// Доступ через точку:
cout << s.name;
// Доступ через стрелку:
cout << p->name;
```

## 20. Массивы и строки (повторение и дополнения)

### Массивы как указатели:
- `int arr[5];` — массив из 5 целых
- `arr` — имя массива, которое **превращается в указатель** на первый элемент
- `&arr` — адрес всего массива (не равно `arr`)

### Пример:
```cpp
int arr[] = {1, 2, 3, 4, 5};
int* ptr_to_arr = arr;   // ptr хранит адрес arr[0]

ptr_to_arr++;            // теперь указывает на arr[1]
cout << *ptr_to_arr;     // 2
```

### Строки — массивы из `char`:
```cpp
char str[] = "Hello";    // массив, который заканчивается '\0'
cout << &str[0];         // адрес первого символа
cout << &str;            // тоже тот же адрес (имя массива)
```
