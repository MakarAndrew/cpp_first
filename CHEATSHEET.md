## 1. Как рождается программа

| Термин | Что это | Пример |
|---|---|---|
| **Препроцессор** | "Повар-подготовщик": работает ДО компиляции, подставляет файлы и текст | обрабатывает `#include <iostream>` |
| **Директива препроцессора** | Команда препроцессору, всегда начинается с `#` | `#include`, `#define` |
| **Компилятор** | Переводчик с C++ на машинный код | `g++ main.cpp -o main` |
| **Линкер** | Сборщик: склеивает куски кода в один готовый файл | работает незаметно после компилятора |
| **Исполняемый файл** | Готовая программа | `./limits` |

## 2. Скелет программы

```cpp
#include <iostream>       // директива: подключить библиотеку ввода-вывода

int main()                // главная функция, точка входа
{
    // это комментарий, компилятор его игнорирует
    std::cout << "Привет!";  // инструкция, обязана заканчиваться точкой с запятой!
    return 0;             // 0 = "программа завершилась успешно"
}
```

| Термин | Что это |
|---|---|
| **main()** | Функция, с которой начинается выполнение программы |
| **Инструкция** | Одна команда компьютеру, заканчивается `;` |
| **Комментарий** | Заметка для людей: `// одна строка` или `/* много строк */` |
| **return** | Вернуть значение и выйти из функции |

## 3. Данные и типы

| Термин | Что это | Пример |
|---|---|---|
| **Переменная** | Именованная коробочка для значения | `int age = 10;` |
| **Объявление** | Создание коробочки | `int age;` |
| **Инициализация** | Первое значение в коробочку | `age = 10;` |
| **Тип данных** | Какого рода значения помещаются в коробочку | `int`, `double`, `char` |

### Основные типы

| Тип | Хранит | Размер (обычно) | Пример |
|---|---|---|---|
| `int` | Целые числа | 4 байта | `int a = 42;` |
| `double` | Дробные числа | 8 байт | `double pi = 3.14;` |
| `char` | Один символ (внутри — число ASCII!) | 1 байт | `char c = 'A';` |
| `bool` | true / false | 1 байт | `bool ok = true;` |
| `std::string` | Текст (это объект класса!) | — | `std::string s = "Привет";` |
| `void` | "Ничего", пустота | — | `void f();` |

## 4. Функции

| Термин | Что это | Пример |
|---|---|---|
| **Функция** | Именованный кусок кода, который можно вызывать | `int add(int a, int b)` |
| **Прототип (объявление)** | Обещание компилятору: "такая функция будет" | `int add(int, int);` |
| **Определение** | Сама реализация функции с телом | `int add(int a, int b) { return a + b; }` |
| **Вызов** | Запуск функции | `add(2, 3);` |
| **Аргумент** | Значение, передаваемое ПРИ ВЫЗОВЕ | `2` и `3` в `add(2, 3)` |
| **Параметр** | "Ячейка" в функции, принимающая аргумент | `int a, int b` в определении |
| **Возвращаемое значение** | То, что функция отдаёт обратно | `return a + b;` |
| **void-функция** | Функция, которая ничего не возвращает | `void hello() { ... }` |

## 5. Ввод и вывод (потоки)

| Термин | Что это | Пример |
|---|---|---|
| **Поток** | "Труба", по которой текут данные | поток вывода, поток ввода |
| **cout** | Объект-робот вывода (на экран) | `std::cout << "Привет";` |
| **cin** | Объект-робот ввода (с клавиатуры) | `std::cin >> x;` |
| **<<** | "Засунуть в поток" | `cout << x;` |
| **>>** | "Достать из потока" | `cin >> x;` |
| **endl** | Перенос строки | `cout << endl;` |
| **Функция-член (метод)** | Личное умение объекта, вызов через точку | `cout.put('A');` `cin.get(c);` `getline(cin, s);` |

## 6. Основы ООП

| Термин | Что это | Пример |
|---|---|---|
| **Класс** | Чертёж / рецепт объекта | `class Dog { ... };` |
| **Объект** | Конкретная вещь, собранная по чертежу | `Dog rex;` |
| **Поле** | Данные внутри объекта | `rex.name` |
| **Метод** | Умение объекта | `rex.bark();` |
| **Пространство имён** | "Папка" для имён, чтобы не было конфликтов | `std::cout` — cout из папки std |
| **using namespace** | "Разрешаю не писать имя папки" | `using namespace std;` |

## 7. Память и числа

| Термин | Что это | Пример |
|---|---|---|
| **sizeof** | Размер типа или переменной в байтах | `sizeof(int)` → 4 |
| **Переполнение** | Значение не влезло в тип и "перекрутилось" | `short s = 32767; s + 1` → `-32768` |
| **ASCII** | Таблица кодов символов | `'A'` = 65, `'a'` = 97 |
| **Область видимости** | Где переменная жива и видна | переменная внутри функции не видна снаружи |
